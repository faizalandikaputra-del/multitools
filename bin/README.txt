Auto Smooth tab needs ffmpeg and ffprobe here (ffmpeg 5.1 or newer, a full build with the prores_ks and libx264 encoders).

Windows : bin/ffmpeg.exe  and  bin/ffprobe.exe
macOS   : bin/ffmpeg      and  bin/ffprobe   (the panel sets the executable bit itself)

Download a static build (for example gyan.dev "essentials" on Windows, evermeet.cx / ffmpeg.org builds on macOS)
and copy only these two files. The cache for exported clips is created in Documents/MultiTool/DeadFrameCache.
